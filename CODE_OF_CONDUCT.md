# Code of conduct

Treat participants with respect. Discuss code and evidence rather than personal
characteristics. Welcome questions, acknowledge mistakes, and offer actionable
feedback. Harassment, threats, discriminatory language, sexualized attention,
and publishing another person's private information are unacceptable.

This applies to repository issues, pull requests, discussions and other project
spaces. Maintainers may edit or remove harmful content and restrict participation.
They should explain decisions privately when practical and apply these rules
consistently. Report concerns privately to the repository owner, `@manziman`,
through a private contact method listed on their GitHub profile; do not post
private details in a public issue.
